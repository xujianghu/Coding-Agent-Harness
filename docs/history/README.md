# 历史材料

[返回文档导航](../README.md) · [当前项目首页](../../README.md)

本目录原样保留项目早期的规格、实施计划和课程过程材料。其中的架构、版本、能力表述、测试数量和后续计划反映当时状态，可能与当前源码不同。

| 材料 | 用途 |
| --- | --- |
| [SPEC.md](SPEC.md) | 早期功能与工程规格 |
| [SPEC_PROCESS.md](SPEC_PROCESS.md) | 早期实施流程与验收要求 |
| [PLAN.md](PLAN.md) | 原始任务分解与实施计划 |
| [AGENT_LOG.md](AGENT_LOG.md) | 早期 Agent 开发过程记录 |
| [REFLECTION.md](REFLECTION.md) | 早期项目反思报告 |

使用和开发当前版本，请从 [快速开始](../getting-started.md)、[架构说明](../architecture.md) 和 [开发指南](../development.md) 阅读。当前能力与测试结果应依据源码和实际运行记录确认。
