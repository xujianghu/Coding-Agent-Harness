## 修复的交互问题

- 无会话时无法浏览当前项目源码。
- 文件读取失败后残留旧内容，重复点击当前面包屑后列表清空。
- 刷新丢失当前页面和选择，旧发送请求完成后清空新会话草稿。
- 配置损坏时项目身份未绑定，打开其他项目按钮无反馈。
- 项目弹窗沿用旧运行状态，任务结束后仍禁止切换。
- 独立历史运行的文件标题与实际读取目录不一致。
- 通用输入框样式覆盖初始化复选框，导致说明文字挤压。
- 目录或文件加载时按钮被卸载，导致键盘焦点丢失。

## 当前入口边界

网页支持项目选择、会话执行、审批、文件只读浏览、Diff、历史和报告。评测任务仍通过评测 CLI 生成；模型凭据和详细运行配置仍通过环境变量、配置文件或 CLI 管理。当前没有网页代码编辑、Git worktree、多用户登录和模型逐 Token 输出。
